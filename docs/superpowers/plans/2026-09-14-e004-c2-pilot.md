# E004 C2 Pilot Readiness Implementation Plan

## Scope

Prepare the repository for the six-run E004 pilot without executing live pilot
or formal runs. Preserve all C1 artifacts.

## Work items

1. Add an explicit exploration condition (`ungated_random`, `linear`, `full`)
   and a persisted random seed. Keep current deterministic behavior as the
   default. Reject condition/flag combinations that would confound the
   ablation.
2. Add seeded ungated-random candidate selection while retaining the existing
   lifecycle, retry, evidence, and attempt-limit bookkeeping.
3. Count replay GUI action attempts separately from successful replay steps,
   assign replay identifiers, and link successful recovery to the first normal
   candidate attempt that follows it.
4. Add a C2 annotation/export and analysis path that retains every normal
   attempt, including missing-before, failed, and evidence-incomplete samples,
   and computes the three frozen primary metrics.
5. Update E004 protocol/registry documentation to match the implemented
   three-condition design and readiness status.

## Verification

- Run focused tests after each implementation slice.
- Run the full test suite, handling the existing sandbox-only browser spawn
